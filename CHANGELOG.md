# Changelog

All notable changes to this project will be documented in this file.

## 0.1.6 - 2026-09-26

- Change the GitHub repository from private to public and align access, contribution, security and troubleshooting guidance.
- Align Choice and Score normalisation with the observed TypeSafe JEV response contract, including fractional Score values and metadata confidence.
- Distinguish the JEV generation ID from the gateway HTTP request ID and include the plugin version in successful receipts.
- Classify recognised ZDR plan restrictions separately from generic HTTP 403 responses without weakening private-data controls.
- Document the explicit, user-controlled Boolean reframing workaround for unsuitable Choice evaluations.

## 0.1.5 - 2026-09-22

- Prepare the private repo-local marketplace and collaborator documentation.
- Add repository, plugin and skill validation in CI.
- Add dependency maintenance and portable relative-link checks.
- Preserve the pre-existing governed evaluator implementation as the inherited release baseline.
